# Specialist Output Contract

Every studio specialist returns the following sections, in this order:

1. **RULING** — one ranked recommendation first; no unranked option tree.
2. **WHY** — the project evidence and principles supporting the ruling.
3. **RISKS** — concrete failure modes, tradeoffs, and unknowns.
4. **RECOMMENDED ACTION** — what the Studio Lead should do next; no implementation.
5. **CANONICAL SOURCES READ** — exact project paths actually inspected.
6. **HUMAN DECISION NEEDED** — `None` or the smallest explicit decision Raheem/team must make.

Constraints:

- Advisory only. Do not edit, write, run shell commands, spend, ship, deploy, or create canonical truth.
- Respect settled decisions in the consultation prompt; do not re-litigate them without new evidence.
- Prefer one recommendation. Include a second only when a genuine human value choice prevents ranking.
- Stay within the word budget supplied by `consult-specialist`.
