# Your Card Game learning path

You do not need to learn the whole repository. We will learn one useful path
through the game at a time.

## Step 1 — Become comfortable looking around

Goal: open files without worrying that you will break something.

1. Run the **Card Game: First Look** CodeTour.
2. Practice `Ctrl+P` to open a file by name.
3. Practice `Ctrl+Shift+F` to search for a word across the game.
4. Learn the difference between a screen, a rule, data, and an asset.

Nothing is edited during this step.

## Step 2 — Learn one visible game experience

Goal: connect something you see while playing to the code that creates it.

Our first subject will be combat after Claude finishes **Combat Satisfaction and
Gameplay Feel**. We will follow one attack from the player's input through:

```text
button or key
    ↓
combat decision
    ↓
damage and state change
    ↓
animation, sound, and game feel
```

I will build a clickable combat CodeTour from the finished files.

## Step 3 — Make one tiny safe change

Goal: experience the complete development loop.

We will choose something harmless and visible, such as explanatory UI text or a
development-only label. Together we will:

1. Find it.
2. Predict what the change will do.
3. Edit it.
4. run the relevant test.
5. See it in the game.
6. inspect the Git change.
7. undo or keep it intentionally.

## Step 4 — Understand a feature folder

Goal: recognize which files belong together.

We will map one feature's screen, rules, data, assets, and tests. Only after we
understand those relationships will we propose moving anything.

## Step 5 — Help organize the real repository

Goal: turn what you learned into permanent structure.

We will audit one category at a time:

1. current documents;
2. historical handoffs;
3. source and review art;
4. runtime assets;
5. feature code.

For every item, we will choose **keep current**, **archive**, **move**, or
**delete after review**. Nothing disappears merely because its filename looks
old.

## What to do right now

Only do Step 1. Open the CodeTour section in the Explorer and start
**Card Game: First Look**. When you finish, tell me which part you want explained
again. There is no test and no wrong answer.
