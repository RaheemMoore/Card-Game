# Welcome to your Card Game workspace

This is your beginner-friendly window into the real Card Game repository.
It is connected to `codex/vscode-learning-workspace`, Codex's isolated branch
for building and teaching this workspace. It started from `development`.

The workspace does not copy, move, or reorganize the game. It only controls
how Visual Studio Code presents the real files to you.

## Play it right now

Press **Ctrl + Shift + B**. The game builds and opens in your browser on the
castle courtyard. Full instructions, including how to run it exactly as a
player gets it, are in [PLAY-THE-GAME.md](PLAY-THE-GAME.md).

## What you should see

The Explorer on the left has two sections:

- **1 — START HERE** contains short lessons written for you.
- **2 — GAME** contains the real application.

That is enough for the first stage. We will add or reorganize project guides
later, after the VS Code interface feels familiar.

## What happens next

1. Open this workspace.
2. Send a screenshot of the entire VS Code window.
3. We will identify the visible areas together: the Activity Bar, Side Bar,
   Editor, Secondary Side Bar, Panel, and Status Bar.
4. We will learn one area at a time using the actual game.

Opening files, expanding folders, searching, and reading code are safe. We will
pause and double-check before edits, moves, deletes, commits, merges, or pushes.

## The branch structure

- **codex/vscode-learning-workspace** — our VS Code learning work.
- **claude/...** — Claude's work, kept separate from ours.
- **development** — the integration branch where approved work comes together.
- **main** — protected production, updated through a pull request.

Look at the branch name in VS Code's bottom Status Bar whenever you are unsure
which version you are viewing. This workspace should say
`codex/vscode-learning-workspace`. Neither Codex nor Claude works directly on
`development`.
