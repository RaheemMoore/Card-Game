# VS Code basics

You only need a few parts of VS Code at first.

## The left side

The vertical strip on the far left is the **Activity Bar**.

- **Explorer** shows files and folders.
- **Search** finds words across the project.
- **Source Control** shows what changed.
- **Testing** runs and displays automated tests.
- **Extensions** shows installed tools.

If the screen ever feels lost, click the top Explorer icon.

## Safe actions

These actions do not change the game:

- Single-click a file to preview it.
- Double-click a file to keep its tab open.
- Use `Ctrl+P` and type part of a filename.
- Use `Ctrl+Shift+F` to search the project.
- Hold `Ctrl` and click a function or imported name to follow it.
- Right-click a name and choose **Peek > Peek Definition**.
- Follow a CodeTour.

## Actions that change something

These deserve a pause and a check:

- Typing inside a file.
- Dragging a file in the Explorer.
- Renaming or deleting a file.
- Clicking Source Control's commit, sync, or publish buttons.
- Running a task whose name says generate, migrate, deploy, upload, or publish.

The Card Game tasks named **Start**, **Test**, **Build**, and **Check Game Assets**
are safe development checks. Starting the game keeps a terminal running; use
the terminal's trash-can icon when you want to stop it.

## Three shortcuts worth learning

| Shortcut | Meaning |
|---|---|
| `Ctrl+P` | Open a file by name |
| `Ctrl+Shift+F` | Search the whole project |
| `Ctrl+Shift+P` | Ask VS Code to perform a named command |

You do not need to memorize anything else yet.
