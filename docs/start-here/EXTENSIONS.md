# Extensions explained

The project already had a strong extension set. The beginner workspace keeps
all of it and adds only three learning-focused tools.

## Added for this workspace

| Extension | Why it helps |
|---|---|
| **Material Icon Theme** | Gives different folders and file types recognizable icons |
| **CodeTour** | Walks through real files one explained step at a time |
| **Bookmarks** | Lets you label important lines and return to them later |

## Understanding code and errors

| Extension | Purpose |
|---|---|
| Error Lens | Shows errors beside the line that caused them |
| Pretty TypeScript Errors | Rewrites complicated TypeScript messages more clearly |
| Oxc | Provides the project's code-quality checks |
| Vitest Explorer | Shows automated tests in VS Code |
| Path Intellisense | Completes file paths while code is being written |

## Navigating the project

| Extension | Purpose |
|---|---|
| GitLens | Explains when and why lines changed |
| Todo Tree | Collects TODO, FIXME, BUG, and DEFERRED notes |
| JSON Crack | Turns complicated JSON data into diagrams |
| Markdown All in One | Improves project-document editing and preview |

## Working with game art and appearance

| Extension | Purpose |
|---|---|
| Gutter Preview | Shows small previews beside image paths in code |
| Luna Paint | Opens and edits raster images inside VS Code |
| Color Highlight | Displays colors beside color values |
| Tailwind CSS | Explains and completes the UI styling classes |

## General helpers

| Extension | Purpose |
|---|---|
| Code Spell Checker | Finds likely spelling mistakes without treating fantasy names as errors |
| Better Comments | Makes warning and explanation comments easier to see |
| Indent Rainbow | Makes nested code blocks visually distinct |
| Python | Supports the repository's asset-processing tools |
| Claude Code | Keeps Claude available in VS Code |

We will only add another extension when it solves a problem you have actually
encountered. More extensions are not automatically a better workspace.
