# Project guides

This is the small current bookshelf. The repository contains many more plans,
handoffs, creative references, and historical files, but they are not all useful
starting points.

You do not need to read these from beginning to end. They are reference books,
not homework.

## Later: the document cleanup

Documents that are not on this shelf have not been declared useless. They are
simply **unclassified** from your perspective. We will review them in groups:

- active source of truth;
- useful reference;
- completed handoff;
- historical archive;
- duplicate or safe deletion candidate.

Clothing, weapon, companion, archetype, combat, and economy documents may still
feed code or AI generation even if they look outdated. We will check references
and current behavior before moving or removing them.
